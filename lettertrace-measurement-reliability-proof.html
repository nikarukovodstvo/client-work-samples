Launch question to acceptance map

Prompt lineage

RELEVANCE

Generated questions need a stable source, intent label, review status, and version so a trend is not moved by a changed cohort.

ACCEPT: cohort hash + intent coverage + dedupe + curated disagreement queue

Provider provenance

DRIFT

Model, route, grounding mode, timestamp, and control-set movement must be attached to every comparable run.

ACCEPT: fingerprint match or explicit NON_COMPARABLE receipt

Signal separation

CITATION

A URL used as a source is not equivalent to the brand being named, recommended, or prominent in the answer.

ACCEPT: cited_hit, brand_mention, recommendation, sentiment stored independently

Sampling confidence

VARIANCE

One stochastic answer cannot define a trend. Replicates and confidence bands expose inconclusive movement.

ACCEPT: sample count + dispersion + minimum effect + INCONCLUSIVE state
