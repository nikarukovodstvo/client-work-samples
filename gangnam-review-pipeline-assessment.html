Gangnam Review Pipeline

A deterministic multi-step agent workflow that normalizes, de-duplicates, translates and validates synthetic clinic reviews before publishing. It fails closed when provenance or semantic checks are weak.

1 · Intake agent

Validates source URL, review ID, clinic alias, rating and Korean text.

2 · Entity agent

Maps aliases to a canonical clinic ID and computes a stable content fingerprint.

3 · Translation agent

Uses a local deterministic dictionary, retaining the original Korean text.

4 · Trust agent

Checks provenance, duplicate fingerprints, rating range and translation coverage.

5 · Publisher

Publishes only validated records; everything else gets a reasoned hold receipt.
