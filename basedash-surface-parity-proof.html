Delivery pattern

Make public promises executable.

Commercial contract: one versioned plan manifest drives pricing, docs, signup copy, entitlements, and legacy redirects. Developer contract: example keys and payloads are generated from validation fixtures, then checked against rendered documentation. A lightweight public-surface crawler fails the release when a retired route or invalid example returns.

This proof uses public, read-only pages only. It does not create an account, use an API key, access customer data, or test private billing behavior.
