Safety invariants

Designed around public Desktop capabilities and current multi-user/API concerns.

Sessions never share history by defaultConversation, tool outputs, approvals, and receipts are keyed to an explicit local session.
Mutation requires visible intentShell, file writes, tunnels, and network actions stop at a reviewable approval card.
Secrets fail closedToken-shaped input is redacted, quarantined, and never echoed to logs or model context.
Recovery never means repeatStable action IDs make a restart resume or return the prior receipt instead of duplicating effects.
