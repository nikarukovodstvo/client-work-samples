Fixed remediation scope

Public release plumbing, not product internals

Deliverables

  • Define one canonical source and support identity for both SDKs.
  • Correct docs, npm/PyPI metadata, README and Issues destinations.
  • Add a machine-readable version/commit/compatibility manifest.
  • Add CI link checks and package-provenance assertions.
  • Publish a compact migration note for existing users.

Acceptance

  • Every official GitHub and Issues link returns the intended live destination.
  • npm and PyPI releases resolve to documented source or an explicit closed-source policy.
  • Release manifest identifies package version, commit and API compatibility.
  • A seeded broken repository URL fails CI.
  • Fresh install documentation and one revision pass QA.
