Acceptance checks

Evidence ledger

  • Malware handling: every flagged path gets hash, classification, disposition and restoration note.
  • Database safety: each purge rule has before/after row counts and a reversible export.
  • Plugin safety: active use, owner, version, PHP support, replacement and regression test are explicit.
  • Forms: test records verify validation, consent, routing and notification without using real visitor data.
  • Cutover: content hashes, URLs, redirects, certificates, cache and analytics are checked before DNS release.

Stop conditions

  • Unknown executable or credential-bearing artifact: quarantine and request human review.
  • Page, post or form reconciliation mismatch: stop cutover.
  • PHP fatal, mail leak, broken consent path or security regression: rollback.
  • No destructive deletion without verified backup and written owner approval.
  • No access to production until written scope, payment gate and staging boundary are accepted.
