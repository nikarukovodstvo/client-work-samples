Canonical delivery pattern

Pricing copy becomes a rendered view, not hand-maintained truth.

Define each feature once: feature key, Free access, Pro access, limit, upgrade message, and public label. Generate the two comparison blocks and the FAQ feature list from that same object. Add a parity test that fails when a page introduces a different entitlement.

This proof audits public copy only. It does not test checkout, accounts, billing, or private product behavior.
